02 / COMPUTATIONAL GRAPH

责任是怎么一层层传回去的

前向：x → z¹ → a¹ → z² → ŷ → L。反向：从 L 出发，每一步乘上局部导数，像接力一样传到每个 W 和 b。

INTUITION / 直觉

为什么误差要“乘权重”传回去？

如果一条连接权重很大，它对输出影响就大，理应承担更多责任；如果权重接近 0，它几乎没参与预测，梯度也接近 0。

所以反向传播不是“平均分摊”，而是按局部导数精确分摊。

03 / THE MATH

每一层，只做两件事

前向：线性 + 激活；反向：把上游梯度乘上本地的两个导数。复杂网络也只是把这件事重复很多次。

FORWARD

前向传播

先线性组合 z = W·a + b，再用激活函数 a = σ(z) 把数值压到 0–1。

LOSS

二元交叉熵

当 ŷ 离真实标签 y 越远，Loss 越大；反向传播要做的，就是降低它。

OUTPUT LAYER

输出层梯度

Sigmoid + 交叉熵有一个非常干净的组合：δ² = ŷ − y。这是整个反向传播的起点。

HIDDEN LAYER

隐藏层梯度

先把输出层梯度按权重传回来，再乘上 Sigmoid 的局部导数 a(1−a)。

WEIGHTS

权重梯度

一句话：上游梯度 × 本层输入。输入越大，这个权重对误差的责任越大。

LIVE CHAIN RULE

当前这一步的链式法则

01 / REQUIRES_GRAD
只有需要梯度的张量才会被记录
W1、b1、W2、b2 设置 requires_grad=True，PyTorch 才会在前向时记录它们的运算。

          
02 / BACKWARD
一次 backward，整张图反向走一遍
loss.backward() 从标量 Loss 出发，按链式法则把梯度累积到每个 leaf tensor 的 .grad 上。

          
03 / ZERO_GRAD
梯度会累加，所以每轮要清零
PyTorch 默认把新梯度加到 .grad 上。训练循环里要写 optimizer.zero_grad()，否则梯度会越加越大。

        

      

    


    

      

        
05 / TRAINING LOOP
一次反向传播，只是走了一步
前向 → Loss → backward → 更新参数 → 清零梯度 → 下一轮。重复很多次，Loss 才会一点点降下来。
